# 通用上下文块（每轮提示词开头都要带上）

> 用法：新开一个 AI 会话时，先粘贴下面这一整块作为「项目背景」，再粘贴当轮任务提示词。
> 已有会话继续开发时，只需带当轮任务块 + 一句话「沿用本仓库现有代码风格与数据表定义」。

```text
# 项目
校园闲置物资循环 AI 平台（Web 应用，参加传智杯 AI 创新应用挑战赛）。
面向本校学生，毕业季闲置教材/被褥/文具/小家电在校内流转，两种模式：低价转售、公益捐赠给通过审核的困难生。不做在线支付与物流，线上达成意向 + 线下自提交割。

# 技术栈（不要换）
Next.js 15 App Router + TypeScript + Tailwind CSS；后端用 Next.js Route Handler（src/app/api/**），不单独起 Node/Python 服务；数据库 SQLite + better-sqlite3（同步 API，不用 ORM）；AI 用阿里百炼 DashScope 的 OpenAI 兼容端点（qwen-vl-max / qwen-plus / text-embedding-v3）；图表 ECharts。

# 硬性约束
1. 所有 AI 调用只在服务端发起，API Key 从 process.env 读取，绝不出现在客户端组件里。
2. 密码用 node:crypto 的 scrypt + 每用户随机盐；会话用 httpOnly cookie 存签名 token；每个 /api 写操作先做服务端登录校验，不信任前端。
3. SQL 一律用 better-sqlite3 的参数化占位（?），禁止字符串拼接。
4. 上传文件校验扩展名与 MIME，限制 5MB，存 /public/uploads，文件名用随机串，不用用户原始文件名。
5. 每次 AI 调用把 prompt 原文与模型原始返回写入 ai_call_logs 表（这是比赛要求的可复现证据）。
6. 数据表结构以我给你的 schema 为准，不要自行增删字段；确需新增先说明理由。
7. 不要引入 Redux/Zustand 之外的状态库，不要引入 shadcn 之类组件库，直接用 Tailwind 写。
8. 代码要能直接运行，不要留 TODO 让我自己补；不要写没用的注释。

# 视觉风格
粉彩色系：背景 #FDF6F0，公益捐赠主色 #F7B2BD，转售辅色 #A8D8EA，AI 能力强调色 #C7CEEA，正文 #4A4A55。三层圆角卡片（页面底 → 区块卡 → 内容卡），圆角 12/16/20px，轻阴影 0 2px 12px rgba(0,0,0,.06)，hover 上浮 2px 并加深阴影。AI 生成过程中显示骨架屏 + 「AI 正在识别…」状态提示。移动端单列，桌面最多 4 列。

# 输出要求
只输出：①新增/修改的文件清单（路径）②每个文件的完整内容 ③我需要在终端跑的命令。不要输出解释性散文，不要重复我已经有的代码。
```

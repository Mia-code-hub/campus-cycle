# 修 Bug 引导话术 + 录屏脚本（对应比赛「≥2 分钟 AI 协同过程复现」）

评分里「过程可复现性 25%」和「意图控制 20%」都要看**你怎么引导 AI 修错**。所以不要藏着 bug，要**故意制造并公开修复**，全程录屏。

## 一、可复用的四步引导模板

```text
第 1 步（贴现象，不贴你的猜测）
「页面报错/结果不对，现象是：______。控制台原文：______。终端原文：______。
 先不要改代码，告诉我你判断的根因和需要我补充的信息。」

第 2 步（要求定位到行）
「定位到具体文件与行号，说明这行为什么会错，给出最小改动方案（不要重写整个文件）。」

第 3 步（要求加防回归）
「改完后，为这个 bug 补一个测试用例或一条断言，保证以后不会再犯。
 同时检查代码里是否还有同类写法，列出来但先不要动。」

第 4 步（要求解释，写进技术文档）
「用 3 句话总结：这个 bug 属于哪类问题（类型/边界/时序/环境），
 我作为开发者做对了哪一步判断，AI 的哪一次修正是无效的。
 我要把这段写进比赛技术文档的『意图控制策略』章节。」
```

第 4 步是关键 —— 评委要看的是**人的判断**，不是 AI 有多神。把这段总结直接抄进技术文档。

## 二、建议现场演示的 3 个「可控 bug」（提前跑一遍，确保能复现）

| # | 场景 | 怎么制造 | 修复话术重点 |
|---|---|---|---|
| 1 | AI 返回带 ```json 包裹导致 `JSON.parse` 崩 | 让 AI 去掉 `safeParseJson` 里的代码块剥离逻辑 | 展示「模型输出不稳定 → 应用层做防御性解析」，这是最典型的 AI 工程问题，讲出来很加分 |
| 2 | 语义搜索搜不到 donate 物品 | 把加权系数从 +0.15 改成 -0.5 或忘过滤 status | 展示「召回 ≠ 排序，业务规则要显式加权」 |
| 3 | 越权：改别人的物品 | 让 AI 在 PATCH 里只按 id 更新、漏了 owner_id | 展示「AI 生成的代码必须过安全审查」，正好对应 R20 的安全复查 |

## 三、录屏清单（阶段 3 期间就要录，事后补不出来）

1. **发布链路**（约 60s）：拍照 → 点「AI 帮我完善」→ 骨架屏 → 字段回填 → 手改一处（徽章变「已修改」）→ 提交。
2. **Prompt 视角**（约 40s）：切到 IDE 里 `src/lib/ai/prompts.ts`，滚动展示 system + few-shot + JSON schema 约束，配一句「我用结构化输出约束模型」。
3. **修 bug 复现**（≥60s，比赛硬性要求）：终端报错原文 → 粘贴给 AI → AI 给出根因 → 最小改动 → 重跑通过 → 补测试。**这一段必须完整，别剪辑跳过。**
4. **语义搜索对比**（约 30s）：同一句「宿舍不占地方的灯」，先演示关键词搜索 0 结果，再演示语义搜索命中 3 件（含 donate 置顶）。
5. **看板与感谢信**（约 40s）：完成一笔捐赠 → 台账 +1 → 看板数字滚动 → 生成环保报告 → 导出 CSV。

总长控制在 6–7 分钟，1080p。录屏时**关掉 IDE 的 API Key 文件**，别把 `DASHSCOPE_API_KEY` 录进去。

## 四、Git 提交纪律（比赛明令禁止一次性提交）

```bash
# 每轮提示词跑完、肉眼验收通过，立刻：
git add -A
git commit -m "feat: 本轮功能（R10 qwen-vl-max 识图生成文案）"

# 修 bug 单独一次提交，message 里写清是谁发现的：
git commit -m "fix: AI 返回带 markdown 代码块导致 JSON.parse 崩溃，加防御性解析（R10 调试中人工定位）"
```

提交前 `git status` 看一眼，**别把 `.env.local`、`data/campus.db`、`public/uploads/*` 提交上去**（密钥泄漏 = 仓库必须删库重推）。

## 五、和另一个 AI 协作时的三个提醒

1. **一轮只给一个任务**。提示词文件里 R1–R22 已经切好了，别一次贴三轮，否则 commit 粒度废掉，可复现性直接失分。
2. **它擅自改你的表结构或换技术栈时，立刻回**：「回退这部分改动，我给你的 schema 与技术栈是硬约束，理由见通用上下文第 6 条。」——这种「人纠正 AI」的对话正是评分点。
3. **每 3–4 轮让它输出一次「当前文件清单与依赖变更」**，你核对后再继续，防止它悄悄引入新依赖（答辩时 `package.json` 里冒出没用的库很难解释）。
